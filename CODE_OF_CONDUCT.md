# Code of Conduct

## Our Standard

FinderPath welcomes contributors and users of every background and experience
level. Be respectful, constructive, and focused on improving the project.

Examples of welcome behavior include:

- Giving specific, actionable feedback
- Assuming good intent while discussing technical disagreements
- Respecting different experience levels and communication styles
- Accepting responsibility and correcting mistakes

Harassment, personal attacks, discriminatory language, threats, doxxing, and
deliberately disruptive behavior are not acceptable in project spaces.

## Scope

This code applies to FinderPath repositories, issues, pull requests, release
discussions, and other project-managed spaces. It also applies when someone is
publicly representing the project.

## Enforcement

Project maintainers may edit or remove contributions that violate this code and
may temporarily or permanently restrict participation when necessary. Decisions
will consider context, impact, and whether harmful behavior is repeated.

To report a conduct concern, contact the maintainer through
[@bhino50](https://github.com/bhino50). Do not put private personal information
in a public issue. Security vulnerabilities should instead use the repository's
[private vulnerability reporting](https://github.com/bhino50/finder-path/security/advisories/new)
channel.

Reports will be reviewed as promptly and confidentially as the available
GitHub communication channel allows.
