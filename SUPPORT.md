# FinderPath Support

## Before Opening an Issue

Use the latest public release and check the
[README](README.md), especially the installation, permissions, and update
sections.

## Get Help

- Use the bug report template when FinderPath behaves incorrectly.
- Use the feature request template for product ideas.
- For installation or usage questions, open an issue and apply the `question`
  label.

Include your FinderPath version, macOS version, the downloaded asset name, and
clear reproduction steps. Remove usernames, server names, IP addresses, file
paths, and other private machine details from screenshots and logs.

## Security Issues

Do not publish vulnerability details in an issue. Follow
[SECURITY.md](SECURITY.md) and use
[private vulnerability reporting](https://github.com/bhino50/finder-path/security/advisories/new).

Support is community-maintained and response times are not guaranteed.
